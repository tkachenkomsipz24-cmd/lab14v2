# Звіт з лабораторної роботи №8

**З дисципліни:** Об'єктно-орієнтоване програмування  
**Тема:** Делегати й лямбда-вирази у практиці колекцій: `CollectionHelper<T>`.  
**Виконав:** студент Ткаченко Максим **Варіант:** №2

---

## 1. Мета роботи

Навчитися передавати поведінку як параметр через делегати `Func`, `Action`, `Predicate`, будувати на цій основі універсальні операції над колекціями та використовувати лямбда-вирази у практиці ООП.

---

## 2. Індивідуальне завдання (Варіант 2)

Реалізувати статичний узагальнений клас `CollectionHelper<T>` з методом `Map`:

* **Метод:** `public static IEnumerable<TResult> Map<TResult>(IEnumerable<T> collection, Func<T, TResult> mapper)`
* **Призначення:** Перетворює кожен елемент колекції `T` на елемент типу `TResult` за допомогою делегата `mapper` (без використання готового LINQ-оператора `.Select()`).
* **Демонстрація:** Перетворити `List<int>` на колекцію рядків (`string`), а `List<Product>` — на колекцію цін (`decimal`).

---

## 3. Структура проєкту

* `lab14v2/CollectionHelper.cs` — статичний узагальнений клас із реалізацією методу `Map`.
* `lab14v2/Product.cs` — допоміжний клас товару (назва та ціна) для демонстрації роботи.
* `lab14v2/Program.cs` — головний файл із точкою входу `Main`, де тестується робота методу з використанням лямбда-виразів.
* `.gitignore` — конфігураційний файл для виключення системних та тимчасових файлів .NET.
